# Paper figures in the project README

The architecture, multi-domain gains and external-evaluation graphics are rendered directly from the corresponding figures in the Time-JEPA manuscript. The PDF files retain their original bytes. PNG files use a white background and a target width of 2,000 pixels for GitHub display; figure content and numbers are unchanged.

[figure-provenance.json](figure-provenance.json) records the paper figure labels, source checksums, render dimensions and software version. These three figures contain diagrams and aggregate results. The data overview is a Markdown table transcribed from the paper's data-composition figure, including the unit of each fine-tuning count.

The current-state decoding table reproduces the paper table labeled `tab:single_domain_main`, including all four variable/condition settings. The reconstruction table reproduces `tab:grounded_consistency`, including mean and sample standard deviation over five probe seeds. The selected single-domain and multi-domain protocols are identified separately in the README.
